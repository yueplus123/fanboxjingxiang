# Fanbox 账号采集助手（Chrome / Edge 插件）

这个插件做两件事，都发生在**你自己的浏览器里**，由你本人登录 Fanbox：

1. **作者检测**：打开 Fanbox 作者页时，弹出一个 400×600 的面板，告诉你账号池里有没有账号已经赞助了他。
2. **采集上报**：在你已登录的 Fanbox 页面左下角点“读取 Fanbox 数据”，选择对应账号，插件读取这个账号的赞助列表、pixivcoban 余额、User ID 等统计信息，并上报到后台。

服务器不再自己打开浏览器登录任何账号，**不保存密码，也不接触你的登录状态（cookies）**。插件只上报读到的统计结果。

## 作者检测

- 绿色：已赞助，列出是哪个账号、方案金额、到期时间，不用再赞助。
- 橙色：账号池里没有账号赞助过他，可以继续赞助。
- 红色：检测不可用（没填密钥 / 密钥不对 / 后端没启动），提示条里会写明原因。
- 不是作者页（首页、支援中列表等）不显示任何提示。
- 面板顶部标题栏可以按住拖动，位置会记住，窗口太小时会自动缩小到能放下。

检测用的是后台各账号**最近一次上报**的数据，不是实时查询。

## 采集上报

1. 在管理后台“账号”页添加账号，只需要填邮箱和备注（**不要填密码**，系统会拒绝带密码的请求）。
2. 在装了本插件的 Chrome 里，亲自登录这个账号（reCAPTCHA、二次验证都由你来完成）。
3. 打开 Fanbox 的“支援中”页面，点左下角“读取 Fanbox 数据”，选择账号，点“读取并上报”。
4. 管理后台的“账号”页会显示读到的昵称以外的数据：User ID、余额、最后赞助支付时间、赞助列表。

注意：
- **界面语言需要是日语**，接口才会返回 pixivcoban 余额。不是日语时余额会显示“没有读到”，请先在 Fanbox 页面里把语言切成日本語。
- 不会自动定时读取，每次需要你主动点一下。
- 账号昵称只显示在 Fanbox 的“账号设置”页里。想连昵称一起读，请在设置页上点“读取并上报”；在其它页面上点，会沿用上一次读到的昵称，不会清空。

### 串号保护

如果两个不同的账号上报了**相同的 User ID**，说明读到的是同一个登录状态（比如上一个账号没退出就切换了）。服务器会拒绝这次上报、保留原有数据，并在账号页写明原因。

## 安装

1. 先启动项目后端（`server/`），它第一次启动会生成插件密钥，保存在 `server/data/ext.key`。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开右上角“开发者模式”。
3. 点“加载已解压的扩展程序”，选择本目录 `checker-extension/`。
4. 点插件的“详细信息 → 扩展程序选项”：
   - 服务地址：默认 `http://127.0.0.1:8787`，部署到服务器后改成服务器地址（**请用 HTTPS**）。
   - 插件密钥：把 `server/data/ext.key` 里的内容复制进去。
   - 点“测试连接”，显示“连接正常”即可。

## 关于密钥和数据

插件密钥只能调用 `/api/ext/*`：问“某个作者有没有被赞助”、拉取账号列表、上报账号统计。它**不能登录后台**。
插件在发送前会检查数据，带有 password / cookie / session 字样的字段会被拒绝；服务器收到也会再拒绝一次。
如需更换，删除 `server/data/ext.key` 后重启后端，再把新密钥填进插件。也可以用环境变量 `EXT_KEY` 指定。

## 支持的作者页网址

`https://xxx.fanbox.cc/…` 和 `https://www.fanbox.cc/@xxx/…`。Fanbox 是单页应用，页面内切换作者时提示会自动更新。

## 测试

- `test/e2e.mjs`：把插件装进 Chromium，用模拟的 Fanbox 页面验证已赞助 / 未赞助 / 非作者页 / 页面内切换。
- `test/errors.mjs`：验证没填密钥、密钥错误、后端没开三种情况的提示。
- `test/panel.mjs`：验证面板的默认位置、拖动、不拖出窗口、记住位置、关闭按钮、小窗口自适应。
- `test/panel-many.mjs`：验证 25 个账号时列表在框内滚动，以及邮箱里带 HTML 时只当文字显示。

这些脚本用到的 `playwright` 装在 `admin-web/node_modules` 里，运行时需要把脚本复制到 `admin-web/` 下再执行。
需要后端在运行，并且 `server/data/ext.key` 存在。
