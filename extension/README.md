# 赞助填卡助手（Chrome / Edge 扩展）

在 Fanbox 的支付页（`payment.pixiv.net`）输入卡密，自动填入卡号、有效期、CVV。**只填写，不会提交**，提交要朋友自己点。

## 安装（开发者模式）
1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开右上角“开发者模式”。
2. 点“加载已解压的扩展程序”，选择本目录 `extension/`。
3. 在扩展的“详细信息 → 扩展程序选项”里填服务器地址，默认 `http://127.0.0.1:8787`。部署后改成你的服务器地址。

## 使用
1. 管理员在后台“赞助台账”新增赞助，把生成的卡密发给朋友。
2. 朋友打开 Fanbox 的支付页，右下角会出现“赞助填卡助手”小面板。
3. 输入卡密，点“填入卡信息”。面板会显示这张卡对应的作者和金额，**请核对后再点提交**。
4. 卡密有次数和时效限制，用完或过期后需要管理员重新生成。

## 还没在真实页面验证的地方
填卡逻辑只在本地模拟表单上测过。Fanbox 支付页的真实输入框如果找不到，面板会写出“没找到：卡号 / 有效期 / CVV”。这时需要：
- 在支付页对应输入框上右键“检查”，把那行 HTML 发给管理员；
- 如果输入框在 iframe 里，还要告诉管理员 iframe 的 `src` 域名，扩展需要补上 `all_frames` 和对应域名。
